## 🚀 Overview

**JARVIS (Just A Rather Very Intelligent System)** is a personal AI assistant designed to provide a smart, interactive, and automated computing experience.

Inspired by the AI assistant from Iron Man, JARVIS aims to combine conversational intelligence, automation, memory, and system-level interaction into one unified assistant.

The goal of this project is to build an AI companion that can understand user commands, manage tasks, remember important information, and assist users in their daily digital activities.

# 📦 Installation

## 1. Clone Repository

```bash
git clone https://github.com/abanikantdas/JARVIS.git
```

## 2. Navigate to Project Folder

```bash
cd JARVIS
```

## 3. Create Virtual Environment

```bash
python -m venv venv
```

Activate environment:

### Windows

```bash
venv\Scripts\activate
```

### Linux/Mac

```bash
source venv/bin/activate
```

---

## 4. Install Dependencies

```bash
pip install -r requirements.txt
```

---

# ▶️ Run JARVIS

Start the assistant:

```bash
python main.py
```

or on Windows:

```bash
start_jarvis.bat
```
